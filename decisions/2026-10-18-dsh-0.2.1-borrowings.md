## 本批采纳

### 1) DeepSeek Search API 对齐（`src-tauri/src/tools/web_search.rs`）
- `need_content=true` 时官方返回每条结果的 `content`（网页正文 Markdown）。`build_inject_text` 现在优先注入正文（按原有单条 snippet 预算截断、总预算和行格式不变），无正文时回退 snippet/summary；来源卡片 UI 仍使用 snippet，**未改 `SearchItem` 结构**。
- 兼容两种 raw 形态：单引擎直连 `{"results":[...]}` 与重排器包装 `{"raw":{"results":[...]},"provider":"deepseek"}`。
- 重试分类修正：`is_retryable` 抽为模块级纯函数，`402 余额不足` 不再自动重试（官方要求充值后手动重试）；408/429/5xx 保持可重试语义。
- 未采纳 `ori_question` / `localization`：当前工具链没有可信的“用户原始问题”来源，且 localization 需要用户 IP；留待后续。
- 已知限制：多引擎聚合路径（`tools/mod.rs::do_aggregated_search` 从 citations 重建 items）不享受 content 优先；单引擎 / 重排路径已生效。

### 2) DeepSeek Fetch API 可选后端（`src-tauri/src/chat_v2/tools/fetch_executor.rs`）
- 新增设置 `web_search.deepseek.fetch_enabled`（默认关闭，仅 "true" 开启），复用 `web_search.api_key.deepseek`。
- 在本地 URL/SSRF 校验之后、本地 GET 之前尝试 `POST /v1/tools/fetch`（30s 超时、Bearer、支持取消）；成功时返回与本地抓取成功路径**相同形状**的 JSON（分页复用 `paginate_content`）；失败静默回退本地抓取，取消除外。
- 默认关闭的理由：云端抓取按成功请求计费（5 元/千次，5 QPS），且对二进制 URL 可能绕过本地二进制物化（PDF/DOCX/图片 → session artifacts）。
- 前端设置页 DeepSeek 面板新增两个开关：`need_content`（搜索返回正文）与 `fetch_enabled`（网页抓取走官方 Fetch）。

### 3) 用户消息密钥/令牌默认脱敏（`src/features/chat/utils/secretMask.ts` + 正文块）
- 借鉴 DSH 0.2.1「已发送消息中的密钥和令牌检测并默认脱敏、按需查看」：仅对**用户消息**做展示级脱敏，识别 `sk-*`、`Bearer *`、GitHub PAT、AWS Access Key、Slack、Google API Key、HuggingFace、通用 `api_key/token/secret/password = ...` 赋值式。
- 默认渲染脱敏文本（保留可识别前缀 + `••••`），正文下方显示「已隐藏 N 处疑似密钥/令牌 · 显示原文/隐藏原文」；不改 store / 数据库 / 实际发送内容。
- 只做展示层是刻意边界：用户是消息作者，复制/导出/搜索仍可用原文。

### 4) 模型目录核查（无需改代码）
- 官方 `deepseek-flash` 当前版本为 **DeepSeek-V4.1-Flash-1017**（上下文 1M、最大输出 384K、支持视觉/工具/思考）。
- 本仓库内置模型 `builtin-deepseek-flash`（label `DeepSeek V4.1 Flash`、model `deepseek-flash`、多模态/思考/工具均开启）已对齐；`max_output_tokens` 保持 65536 是产品侧保守上限，未在本次改动。
